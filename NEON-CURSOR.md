# Neon arrow cursor

The cursor is an original SVG interpretation of the supplied reference: dark violet arrow face, bright pink beveled outline and cyan/blue stem. No checkerboard is included. The local vector remains sharp at high display densities. A subtle glow animates, and the arrow compresses on click. Its tip is aligned near the pointer hotspot.

Native input, text selection, keyboard, driving, carousel, mobile and reduced-motion fallbacks remain. Production build and browser validation passed for animation, click response, dialogs, forms and responsive fallback.
