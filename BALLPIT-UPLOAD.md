# Upload Ballpit background

1. Extract joyno-ballpit-background-update.zip.
2. Open joynojohn-beep/-explore-joyno on GitHub, then Add file > Upload files at the repository root.
3. Upload the extracted src folder and Markdown files, preserving src/components and all paths. Upload files, not the ZIP or an enclosing folder.
4. Commit to main and wait for the latest Vercel production deployment to show Ready.
5. Refresh https://explore-joyno.vercel.app/#standard.

No dependency or Vercel setting changes are needed. This ZIP contains local tested changes; uploading it publishes through the existing Git connection.
