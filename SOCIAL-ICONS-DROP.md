# Falling social icons

The hero megaphone is replaced by nine glossy dimensional discs: Facebook, Instagram, TikTok, YouTube, Twitter/X, LinkedIn, Pinterest, Reddit and Website. Each uses a local SVG mark, bevel highlights, rim depth and independent perspective tumbling. Staggered falling and bounce keyframes loop above a curved lavender ribbon, inspired by the user-supplied recording. This is decorative animation, not a collision simulation.

No new dependencies, remote media or WebGL contexts are added. Desktop retains the two-column hero; mobile places the scene below the actions. Reduced-motion preferences display a static 3-by-3 arrangement. Content, links and cursor remain unchanged. Production build, desktop/mobile layout, all nine icons, contact dialog, reduced motion and static-page checks passed.
